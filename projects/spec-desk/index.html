§Spec Desk

Drop a spec book here

Open a project manual PDF and Spec Desk splits it into CSI sections, numbers every paragraph, and keeps the page each one came from.

  1. Split: every section, paragraph and page, with a coverage check so nothing falls through.
  2. Ask: questions answered only from the spec, with the exact quote and page.
  3. Compare: line up a proposal, contract or submittal against chosen sections.
  4. Drawings: check sheet numbers, references like 5/A-501, and finish tags across architectural and shop drawing sets.

The PDF is read in your browser. Text goes to Claude only when you ask a question, summarize a section, or run a comparison.
