Sage to Innergy

Reads Sage AP journals (Enter Invoices, Import Invoices, credit card payments), keeps only the lines charged to a job, and fills Dani’s INNERGY_addedExpenses workbook. Macros, the API key and the Innergy lists stay as they are. Everything runs in this browser; nothing is uploaded.

Then, in Excel

  1. Open the downloaded workbook and click Enable Content so the macros run.
  2. Read the Review sheet. Rows marked in yellow need a work order, budget group or vendor picked.
  3. Fix those on the Input sheet with its dropdowns. Change anything else there too.
  4. Run the duplicate check, then post to Innergy as usual.
  5. Next time, drop this same workbook here. The tool saves your fixes to the Rules sheet and fills them in for you.
