# Concepts in Millwork — AI Projects

Tools built for Concepts in Millwork (CIM).

| Project | What it does | Open it |
|---|---|---|
| [Quality Tracker](projects/quality-tracker/) | Report quality issues from the shop floor (installable app) and see trends on a dashboard. Data is stored in CIM's SharePoint. | [Live Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/quality-tracker/) |
| [Spec Desk](projects/spec-desk/) | Read spec books, drawings, proposals and estimates; check them against each other with sources for every finding; build room schedules and Microvellum import files. | [Live Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/spec-desk/) |
| [Purchasing Desk](/projects/purchasing-desk-beta1/purchasing-desk/) | A weekly purchasing assistant that turns supplier price documents into a quick review and an Innergy update file. | [Live Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/purchasing-desk-beta1/purchasing-desk/Purchasing-Desk-Beta.html/)

Each project folder has its own README with setup instructions.
