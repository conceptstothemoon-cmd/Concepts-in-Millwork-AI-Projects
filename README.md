# Concepts in Millwork — AI Projects

Tools built for Concepts in Millwork (CIM).

| Project | What it does | Open it |
|---|---|---|
| [Quality&nbsp;Tracker](projects/quality-tracker/) | Report quality issues from the shop floor (installable app) and see trends on a dashboard. Data is stored in CIM's SharePoint. | [Live&nbsp;Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/quality-tracker/) |
| [Spec&nbsp;Desk](projects/spec-desk/) | Read spec books, drawings, proposals and estimates; check them against each other with sources for every finding; build room schedules and Microvellum import files. | [Live Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/spec-desk/) |
| [Purchasing&nbsp;Desk](projects/purchasing-desk/) | A weekly purchasing assistant that turns supplier price documents into a quick review and an Innergy update file. | [Live Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/purchasing-desk/) |
| [Bid&nbsp;Screener](projects/bid-screener/) (beta) | Screen bid invites by GC tier with warnings, track bid review, and ask questions about past Innergy estimates. Data is stored in CIM's SharePoint; Claude reads invites through a small Azure Function. | [Live Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/bid-screener/) |
| [HR&nbsp;Hub](projects/hr-hub/) | Onboarding, offboarding and transfer checklists: builds only the steps that apply to each person, gives every owner their own task list, and shows HR what's overdue. Data is stored in CIM's SharePoint. | [Live&nbsp;Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/hr-hub/) |
| [Job&nbsp;Cost&nbsp;Pilot](projects/job-cost/) | Installer mileage from phones, Sage and Innergy cost imports, and a month-end WIP schedule for Accounting. Data is stored in CIM's SharePoint. | [Live&nbsp;Site](https://conceptstothemoon-cmd.github.io/Concepts-in-Millwork-AI-Projects/projects/job-cost/) |

Each project folder has its own README with setup instructions.
